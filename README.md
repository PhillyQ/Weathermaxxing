# WeatherMaxxing

One page that reads the outdoors for any place: current conditions, the next 24 hours, a planner for a block of time, the week ahead, light and season, air quality, Washington mountain snow levels, NOAA's longer outlooks, and how today compares with the last 35 years.

It is a single self-contained page. Weather, air quality and history come from Open-Meteo; alerts, written forecasts and outlooks come from the U.S. National Weather Service and NOAA; sunrise and sunset are calculated in the page.

Built for personal, non-commercial use.
